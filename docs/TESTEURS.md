# Tester Bernard — guide pour les testeurs

Merci d'essayer Bernard ! Bernard déménage vos comptes, documents, réglages et
applications d'un ancien ordinateur vers un nouvel ordinateur sous Linux.
Il ne modifie **jamais** l'ancien ordinateur, et tout est annulable sur le
nouveau.

## Ce qu'il vous faut

- L'ancien ordinateur (sous Linux : Zorin OS, Linux Mint, Ubuntu ou Debian),
  **sauvegardé** au préalable, par prudence.
- Le nouvel ordinateur, avec Linux fraîchement installé.
- Les deux sur le même réseau (Wi-Fi ou câble), ou un disque externe.
- Une heure devant vous (selon la quantité de données).

## Comment faire

1. Sur **les deux** ordinateurs, téléchargez
   [bernard_amd64.deb](https://github.com/bernard-linux/bernard/releases/latest/download/bernard_amd64.deb)
   et double-cliquez dessus pour l'installer.
2. Ouvrez **Bernard** depuis le menu des applications, sur les deux.
3. Sur le nouveau : « Ceci est le nouvel ordinateur ». Sur l'ancien : « Ceci
   est l'ancien ordinateur », puis tapez le code affiché par le nouveau.
4. Choisissez ce qui vient, lancez, attendez la fin, **redémarrez** le nouvel
   ordinateur.
5. Ouvrez le bilan rangé dans vos Documents et suivez sa liste de vérifications.

Gardez l'ancien ordinateur intact quelques semaines.

## Ce qui nous intéresse

- Tout ce qui **manque** sur le nouvel ordinateur.
- Tout ce qui vous a **surpris ou inquiété** (un mot incompris, une question
  bizarre, une attente sans explication).
- Les **messages d'erreur** (une capture d'écran suffit).

## Nous le dire

- Sur GitHub : [ouvrir un retour d'essai](https://github.com/bernard-linux/bernard/issues/new?template=retour-essai.yml)
  (un petit formulaire) ;
- ou par e-mail à la personne qui vous a proposé l'essai.

Joignez si possible le fichier `rapport.json` indiqué à la fin de la migration.
