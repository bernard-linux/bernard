Dépôt APT de Bernard

Bernard, l'assistant de migration vers Linux. Le plus simple : téléchargez bernard_amd64.deb et double-cliquez dessus ; ce dépôt est alors ajouté tout seul, et Bernard se met à jour avec le reste du système.

Ou, dans un terminal :

wget -qO- https://bernard-linux.github.io/bernard/bernard-archive-keyring.gpg | sudo tee /usr/share/keyrings/bernard-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/bernard-archive-keyring.gpg] https://bernard-linux.github.io/bernard stable main" | sudo tee /etc/apt/sources.list.d/bernard.list
sudo apt update && sudo apt install bernard

English: download bernard_amd64.deb and open it; this repository is added automatically so Bernard gets updates with the rest of the system.
